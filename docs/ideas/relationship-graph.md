# 灵感：人物与世界设定关系网

## 核心想法

把人物、地点、组织、物品、事件、能力、伏笔与世界规则表示为节点，把它们之间的关系表示为边，形成可查询、可视化的设定网络，而不只是一组彼此孤立的 Markdown 页面。

## 初步模型

- 节点：人物、地点、组织、物品、事件、能力、物种、规则、伏笔。
- 关系：隶属、亲属、敌对、盟友、持有、位于、参与、知情、因果、约束、伏笔指向。
- 边属性：关系类型、方向、证据出处、首次成立章节、失效章节、公开层级（正文已知／作者侧）、置信状态（已定／推断／待确认）。
- 时间切片：允许查看“截至第 N 章”的关系网，避免未来信息污染当前写作视图。

## 可用交互

- 从角色卡或设定词条打开局部关系网，并逐层展开相邻节点。
- 按章节、关系类型、公开层级和正典状态筛选。
- 点击边可回到对应正文或设定文件中的证据位置。
- 在写作前检查孤立节点、冲突关系、时间线矛盾与尚未回收的伏笔。
- AI 只读取当前视图允许的子图；writer 与 planner 使用不同安全投影。

## 范围说明

这是后续的产品方向，不属于当前实现范围。真正动手设计时优先复用现有的 Sidebar DTO、anchor、revision 与 profile 隔离机制，不要另建一套脱离 Markdown 正典的数据真相源。
